## Full description (≤4000 chars)
SquadShelf is a local-first Markdown reader for Android.

Open any .md file straight from your file manager — it renders instantly as a clean, readable document. Browse your Downloads folder inside the app, or drop a file onto the page. No cloud, no sign-up, no tracking: your notes stay on your device.

WHAT YOU GET
• Tap-to-open: file manager → SquadShelf → rendered document (content:// and file:// URIs both supported)
• Directory navigator: walk folders inside Downloads, tap a .md file to read it
• Safe fallbacks: "Open File" picker and drag-and-drop if the file manager route doesn't fit
• Dark theme tuned for big screens and foldables (built on a Galaxy Z Fold 5)
• Truly offline: Markdown rendering ships inside the app — no CDN, no network needed after install

WHAT IT ISN'T (yet)
This is v0.1 beta. Markdown *editing* isn't in — SquadShelf reads, it doesn't write. Cloud sync, theming options, and deeper storage access (SAF) are on the roadmap; feedback decides the order.

PERMISSIONS
• Internet — required by the embedded web engine only; the app makes no outbound calls.
• Read external storage (Android 12 and below) — only for the in-app file browser.
